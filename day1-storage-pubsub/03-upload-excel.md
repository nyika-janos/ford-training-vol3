# Day 1 - Exercise 3

# Upload an Excel File

## Objective

Upload an Excel file into the landing zone.

---

## Estimated Time

5 minutes

---

## Input File

Use:

```
mli_mapping.xlsx
```

provided during the training.

---

## Steps

### Step 1

Open:

```
landing/
```

inside your bucket.

---

### Step 2

Click:

```
Upload Files
```

---

### Step 3

Select:

```
mli_mapping.xlsx
```

---

### Step 4

Wait for the upload to finish.

---

## Validation

Verify:

```
landing/mli_mapping.xlsx
```

exists.

---

## Explore Metadata

Open the file.

Review:

- File size
- Creation timestamp
- Storage class
- Object path
