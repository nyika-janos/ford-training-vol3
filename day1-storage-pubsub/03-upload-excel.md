# 1. nap - 3. gyakorlat

# Excel-fájl feltöltése

## Cél

Tölts fel egy Excel-fájlt a landing zone-ba.

---

## Becsült idő

5 perc

---

## Input fájl

Használd a training során biztosított:

```
mli_mapping.xlsx
```

---

## Lépések

### 1. lépés

Nyisd meg a:

```
landing/
```

foldert a bucketeden belül.

---

### 2. lépés

Kattints erre:

```
Upload Files
```

---

### 3. lépés

Válaszd ki:

```
mli_mapping.xlsx
```

---

### 4. lépés

Várd meg, amíg az upload befejeződik.

---

## Ellenőrzés

Ellenőrizd, hogy a:

```
landing/mli_mapping.xlsx
```

létezik-e.

---

## A metadata vizsgálata

Nyisd meg a fájlt.

Tekintsd át:

- File size
- Creation timestamp
- Storage class
- Object path
