# 1. nap - 5. gyakorlat

# Subscription létrehozása

## Cél

Hozz létre egy subscriptiont, amely képes message-eket fogadni a topictól.

---

## Becsült idő

10 perc

---

## Lépések

### 1. lépés

Nyisd meg:

```
file-arrived-topic-<firstname>
```

---

### 2. lépés

Kattints erre:

```
Create Subscription
```

---

### 3. lépés

Subscription name:

```
file-arrived-sub
```

---

### 4. lépés

Delivery Type:

```
Pull
```

---

### 5. lépés

Hagyd meg a default értékeket.

Kattints erre:

```
Create
```

---

## Ellenőrzés

Ellenőrizd, hogy a:

```
file-arrived-sub
```

létezik-e.

---

## Megbeszélés

Miért lehetnek egyszerűbbek a Pull subscriptionök tanulási és testing célokra?
